# سياقتي فوكاب (Siyaqati Vocab) 🚗🇲🇦
### تطبيق تفاعلي لاختبارات ومصطلحات رخصة السياقة بالمغرب (صنف ب)
**Interactive Moroccan Driving License (Permis B) Vocabulary & Quiz App**

---

## 🌟 نظرة عامة (Overview)

تطبيق ويب تفاعلي حديث وشامل مُصمم خصيصاً لمساعدة المترشحين لاجتياز امتحان رخصة السياقة بالمغرب (صنف ب - Permis B) من خلال:
1. **161 سؤالاً تفاعلياً** مستخرجاً بدقة من السلاسل الرسمية (سلسلة 1، 2، 5، و6).
2. **صور المشاهد الطرقية الأصلية** المستخرجة بدقة عالية مع إمكانية التبديل بين صورة المشهد والشريحة الأصلية الكاملة مع ميزة التكبير.
3. **نظام نطق صوتي متكامل باللغة العربية (TTS)** يقرأ نصوص الأسئلة والخيارات كاملة، مع أزرار استماع فردية لكل خيار وخاصية القراءة التلقائية (Auto-Play).
4. **شرح قانوني مفصل** لكل سؤال يوضح سبب اختيار الجواب الصحيح استناداً إلى **مدونة السير المغربية**.
5. **معجم مصطلحات السير** (عربي، فرنسي، وشرح بالدارجة المغربية مع نصائح الامتحان الرسمي).
6. **لوحة تتبع التقدم والجاهزية** تفرق بين الأجوبة الصحيحة والخاطئة مع احتساب نسبة النجاح ومطابقتها لعتبة الامتحان المغربي (32/40 أي 80%).

---

## 🚀 المميزات الرئيسية (Key Features)

- **لوحة تحكم روسو (Rousseau Console)**: أزرار مرقمة من 1 إلى 4، زر التصحيح (Correction)، وزر التأكيد (Valider) لمحاكاة بيئة الامتحان الحقيقي تماماً.
- **القراءة الصوتية العربية (Arabic Audio TTS)**:
  - استماع لصوت السؤال والخيارات كاملة مع الترقيم بالكلمات العربية (واحد، اثنان، ...).
  - زر نطق منفصل لكل خيار لاختبار الاستيعاب الفردي.
  - خاصية القراءة الصوتية التلقائية عند الانتقال بين الأسئلة.
- **لوحة النتائج والإحصائيات**:
  - رصد دقيق للإجابات الصحيحة (Right) والإجابات الخاطئة (False).
  - تحديد مستوى الجاهزية ونسبة النجاح مع حد النجاح القانوني (80%).
  - بنك الأخطاء المخصص لإعادة مراجعة الأسئلة التي تم التعثر فيها فقط.
- **شروحات مدونة السير المغربية**:
  - نص المادة القانونية (مثل المادة 15، قواعد التجاوز، حدود السرعة، مسافات الأمان، الوقوف والتوقف).
- **تصميم متجاوب بالكامل (RTL)**: تجربة مستخدم سلسة على شاشات الهواتف والحواسيب واللوحات الذكية بتصميم داكن مريح للعينين.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Node.js & Express (لإدارة خادم التطوير وتوجيه طلبات تحويل النص إلى صوت TTS).
- **Build Tool**: Vite 8.
- **Testing**: Node Test Runner (`node:test`) مع اختبارات وحدة لمحرك التقييم وحساب النقاط.

## 📦 التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات الأساسية
- Node.js (v18 فما فوق)
- npm أو bun

### خطوات التثبيت:
```bash
# استنساخ المستودع
git clone https://github.com/bilalchellaoui123-coder/siyaqati-vocab.git
cd siyaqati-vocab

# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

### تشغيل الاختبارات:
```bash
npx tsx --test src/utils/quizEngine.test.ts
```
